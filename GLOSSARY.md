# GLOSSARY: System & MCP Architecture

Canonical domain terms for the retro-superfx MCP tooling and verification systems.

### MesenMCP
A standalone Python 3 MCP server that orchestrates headless Mesen CE instances, executing test ROMs with dynamic Lua harnesses, indexing 24-bit `.dbg` / `.cpu.sym` build artifacts, capturing framebuffers, and validating SuperFX math/render routines.

### RetroLspMCP
An in-process MCP server integrated into `retro-lsp` using the official Java MCP SDK and Jackson 3. Exposes AST inspection, X-GSU macro expansion, SuperFX invariant checking, and symbol resolution over stdio and SSE.

### StudioMCP
A headless MCP server packaged within `sfx-studio` that exposes offline asset and level authoring operations—such as packing, importing, and validating Atlas Documents and Level Documents—to agent workflows over stdio.

### ca65 Debug File (.dbg)
Structured debug metadata generated by `ld65 --dbgfile` containing modules, file offsets, scopes, and symbol address mappings. Serves as the authoritative source of truth for symbol resolution in Mesen and MCP tools.

### BuildArtifactIndex
A pure in-process 24-bit symbol, PC-span, and memory-region index in `mesen_mcp.artifacts` constructed from `ca65 Debug File (.dbg)` and `.cpu.sym` outputs via `from_dir` or in-memory `from_strings`. Retains single-pass `DbgData`, resolves unified symbol aliases (`OUTPUT`, `.dot`, `_function`, `scope::`), translates Game Pak RAM Bank `$70`/`$71` addresses to linear `gsuWorkRam` offsets while rejecting non-GSURAM overrides, computes 512-byte cache spans, and checks build staleness without coupling to `MesenRunner`.

### Math Harness Generation
A mechanism whereby `SfxTestSession` emits ephemeral 24-bit Lua harnesses (`emit_lua_overrides`, `emit_lua_expectations`, `gsuMemory` execution callbacks, and non-mutating `test.lua` synchronization) rather than requiring a persistent TCP socket inside Mesen, executing routines and reading back results via dual-channel JSON files and stdout sentinels.

### Render Capture
Extraction of the SNES PPU / SuperFX framebuffer into an image (PNG) along with quantitative scene metrics (active bounding box, non-black pixel count) for agent visual and rasterization verification.

### SfxTestSession
A deep execution and lifecycle module in `mesen_mcp.session` composing `BuildArtifactIndex` and `MesenRunner`. Encapsulates staleness-gated incremental `make all` compilation, deterministic `.sfc` ROM discovery, 24-bit `Math Harness Generation` across Bank `$70`/`$71` GSURAM and ROM `GSUCODE`, ephemeral temp-file cleanup, and `bytes`-safe timeout recovery behind a unified `run_harness` interface.

### MesenRunner
A port/adapter interface (`Protocol`) in `mesen_mcp.session` decoupling Mesen CLI execution from caller tools, supporting `SubprocessMesenRunner` for real headless execution and `FakeMesenRunner` (capturing `last_lua_code` / `lua_scripts` and `on_run` hooks) for fast, in-memory unit testing.
