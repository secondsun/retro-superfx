# GLOSSARY: System & MCP Architecture

Canonical domain terms for the retro-superfx MCP tooling and verification systems.

### MesenMCP
A standalone Python 3 MCP server that orchestrates headless Mesen CE instances, executing test ROMs with dynamic Lua harnesses, parsing `.dbg` symbol tables, capturing framebuffers, and validating SuperFX math/render routines.

### RetroLspMCP
An in-process MCP server integrated into `retro-lsp` using the official Java MCP SDK and Jackson 3. Exposes AST inspection, X-GSU macro expansion, SuperFX invariant checking, and symbol resolution over stdio and SSE.

### ca65 Debug File (.dbg)
Structured debug metadata generated by `ld65 --dbgfile` containing modules, file offsets, scopes, and symbol address mappings. Serves as the authoritative source of truth for symbol resolution in Mesen and MCP tools.

### Math Harness Generation
A mechanism whereby the MCP server generates ephemeral or templated Lua harnesses and input fixture ROMs, rather than requiring a persistent TCP socket inside Mesen, executing routines and reading back results at test exit callbacks.

### Render Capture
Extraction of the SNES PPU / SuperFX framebuffer into an image (PNG) along with quantitative scene metrics (active bounding box, non-black pixel count) for agent visual and rasterization verification.

### SfxTestSession
A deep execution and lifecycle module in `mesen_mcp.session` that encapsulates SuperFX test compilation (`make clean all`), compiled ROM locating, `.dbg` symbol parsing with `.cpu.sym` fallback, `OUTPUT` alias resolution, and headless Mesen subprocess execution behind a unified interface.

### MesenRunner
A port/adapter interface (`Protocol`) in `mesen_mcp.session` decoupling Mesen CLI execution from caller tools, supporting `SubprocessMesenRunner` for real headless execution and `FakeMesenRunner` for fast, in-memory unit testing.
